# 中国农业大学教务选课余量监控助手

## Google Chrome 扩展版（当前推荐）

已经提供无需 Tampermonkey 的 Manifest V3 扩展。安装说明和安全边界见 [`chrome-extension/README.md`](./chrome-extension/README.md)，需要在 `chrome://extensions/` 中选择包含 `manifest.json` 的 [`chrome-extension`](./chrome-extension/) 文件夹。

扩展版会复用已经登录的教务页面和学校原生查询/选课流程：定期填写课程名并点击“查询”，解析“剩余容量”，符合条件时只提交一次选课。发现余量后，它会在一次受校验的原生选课调用期间自动确认全部 `confirm`，包括第一层班级确认和随后出现的课程组确认，并在结束后恢复页面函数。

## Tampermonkey 兼容版（保留）

[`cau-course-watcher.user.js`](./cau-course-watcher.user.js) 是原 Tampermonkey 用户脚本版本。

脚本不会保存账号或密码，也不会绕过验证码、登录限制、选课条件或时间冲突检查。用户勾选“本次授权”后，脚本会自动点击本次目标课程选课流程中的所有 JavaScript“确定”弹窗，包括第一层班级确认和动态内容的课程组确认；遇到验证码、会话失效、连续网络错误或无法验证的提交结果时，它会暂停并通过面板、提示音和桌面通知反馈。

## Tampermonkey 版安装

1. 在 Chrome、Edge 或 Firefox 中安装 Tampermonkey。浏览器扩展属于第三方软件，请从浏览器官方扩展商店安装。
2. 打开 Tampermonkey，选择“添加新脚本”。
3. 删除编辑器里的示例内容，将 [`cau-course-watcher.user.js`](./cau-course-watcher.user.js) 的全部内容粘贴进去并保存。
4. 登录 `https://newjw.cau.edu.cn/`，进入当前轮次的学生选课页面。右上角会出现“选课余量监控助手”面板。

如果你安装过旧版本，请在 Tampermonkey 编辑器中全选并替换为当前文件，保存后刷新选课页面。面板标题应显示 `v1.2.0`；原有课程配置会保留，但黄色“本次授权”需要重新勾选。

账号和密码不要写进用户脚本；直接使用浏览器中的正常登录状态即可。

## 推荐使用流程

1. 在“课程名称”中输入完整课程名，例如 `羽毛球`。
2. 保持“智能精确”。如果同名课程有多个班，建议再填写“教师”“课序号”或“时间关键词”，防止选到不想要的班。
3. 点击“仅查询一次”，检查面板返回的匹配班级和余量是否符合预期。这个按钮不会自动选课。
4. 确认条件后勾选黄色区域里的“本次授权”。这个勾选不会保存，刷新页面后必须重新确认。
5. 点击“开始监控”。发现满足最低余量的班级后，脚本会按设置选择一次，然后停止。
6. 随时按 `Esc` 或点击“立即停止”终止监控。

建议保持选课标签页可见，并关闭电脑自动睡眠。浏览器可能限制后台标签页的定时器，因此将页面长期放在后台会降低刷新频率。

## 配置说明

| 配置 | 含义 |
| --- | --- |
| 课程名称 | 必填。会同时写入学校页面的“课程（编号/名称）”输入框，并用于结果二次匹配。 |
| 名称匹配 | 默认“智能精确”：输入 `羽毛球` 可匹配结果中的 `羽毛球（1）`，但如果输入本身带编号（如 `羽毛球（2）`）则严格区分。只有确实需要宽泛搜索时才选“包含关键词”。 |
| 课程编号 | 可选，精确匹配。 |
| 教师 | 可选，包含匹配。 |
| 课序号 | 可选，精确匹配；同名多班时最可靠。 |
| 校区 | 可选，包含匹配。 |
| 时间关键词 | 可选，忽略空格后包含匹配，如 `星期六1-2节`。 |
| 刷新间隔 | 默认 5 秒，最低 3 秒。脚本另外加入随机抖动，避免机械式固定频率。 |
| 最低余量 | 只有剩余容量达到此值才尝试选课，默认 1。 |
| 最多查询次数 | `0` 表示不限；可用它限制一次运行的最长查询次数。 |
| 多班选择策略 | 默认在所有符合条件且有余量的班中选择余量最多者，也可改为页面第一班。 |
| 显示已满课程 | 会取消学校页面的“不显示已满课程”，便于确认目标存在以及观察 0 到正数的变化。 |
| 自动点击全部确定弹窗 | 用户勾选“本次授权”后，脚本只在当前目标课程的同步选课调用期间临时把网页自身的 `confirm` 处理为“确定”，因此班级确认和内容动态变化的课程组确认都会自动通过；调用结束后立即恢复浏览器原始弹窗函数。只有“确定”的 `alert` 也会自动收集到运行日志。 |

刷新间隔越短并不保证越容易成功，反而可能触发学校服务器限流、会话异常或账号保护。默认的 5 秒加随机抖动是更稳妥的起点。

## 自动处理与暂停条件

脚本会自动处理：

- 自由选课页尚未打开时，切换到“自由选课”。
- 查询请求未结束时禁止重复查询。
- 网络或页面短暂异常时逐步退避；连续 5 次异常后暂停。
- 提交瞬间名额被抢走时，短暂退避后继续监控。
- 通过“选课结果查看及退选”内的通知单号二次验证是否真正选中。
- 成功后立即停止，避免重复提交。
- 通过页面环境桥接调用学校原生 `xsxkFun(...)` 完整流程，并仅在该次调用期间自动确认其中所有 `confirm`；确认文字会逐条写入运行日志。

脚本会暂停并要求人工处理：

- 登录会话失效或页面跳回登录界面。
- 学校要求输入验证码；脚本不会识别或代填验证码。
- 学校打开验证码区域、冲突选择新窗口或其他不能等价为“点击确定”的交互。
- 学校返回时间冲突、限选条件、学分限制、未到选课时间等不可重试错误。
- 页面没有返回明确结果，且“选课结果查看及退选”也无法验证成功。
- 页面结构变化，找不到关键输入框、查询按钮或表格列。

## 故障排查

- **没有出现配置面板**：确认 Tampermonkey 已启用，并确认当前地址以 `https://newjw.cau.edu.cn/jsxsd/xsxk/xsxk_index` 开头。
- **一直显示“其他选课页”**：点击面板中的“进入自由选课”，或手动点击页面顶部的“自由选课”。
- **查询不到课程**：先在学校页面手动输入同样的课程名查询；检查是否勾选了“不显示限选课程”或其他学校页面筛选条件。脚本只主动控制课程名称和“显示已满课程”，其余学校页面筛选项保持原样。
- **找到课程但不选择**：检查余量是否达到“最低余量”，操作列是否有“选课”，以及教师、课序号、校区、时间等条件是否全部匹配。
- **桌面通知没有出现**：Tampermonkey 通知可能被浏览器或系统禁用；面板日志和提示音仍可使用。
- **页面后台运行变慢**：保持标签页可见、浏览器窗口不最小化，并避免电脑睡眠。

## 已核对的页面结构

脚本按 2026-09-14 实际页面核对：外层页面为 `xsxk_index`，自由选课内容位于 `mainFrame`，课程查询由页面原生 `queryKxkcList()` 发起，数据表含“课程名、课序号、上课教师、上课时间、上课校区、剩余容量、操作”等列。选课链接调用 `xsxkFun(...)` 显示第一层确认，然后进入 `xsxkOper(...)`；后者可能根据 `kctxmc` 动态显示“该课程属于某课程组，是否确认选择”。脚本使用带参数白名单和请求令牌的页面环境桥接，在已获得“本次授权”时完整调用 `xsxkFun(...)`，只在这次同步调用期间将所有 `confirm` 记录并视为“确定”，随后立即恢复原函数。验证码和学校的实际校验逻辑不受影响。如果学校后续改版，脚本会在无法识别关键结构时停止，而不会盲目点击。

## 隐私与边界

- 配置只保存在 Tampermonkey 的脚本存储中；不包含账号、密码或 Cookie。
- 脚本只匹配中国农业大学教务选课入口域名和路径。
- 不向第三方服务器发送日志或配置。
- 不绕过验证码、登录、限选条件、时间冲突检查或学校的其他保护机制。
- 使用前请确认遵守学校的选课规则和网络使用要求。
