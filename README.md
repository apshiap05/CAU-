# CAU 选课余量监控助手

面向中国农业大学正选阶段的课程余量查询与选课辅助工具。如果体育课、通识课等课程没有抽签中，可以在遵守学校规则的前提下，用它减少重复手动刷新。
（人话：没抢到通识，体育，美育，英语的可以试试用这个捡漏）

本项目提供两种版本：Google Chrome 扩展插件，以及兼容 Chrome、Edge、Firefox 等浏览器的 Tampermonkey 用户脚本。两者均复用浏览器中已经登录的教务会话和学校页面原生流程，不涉及账号、密码或 Cookie等数据。

## 插件工作模式

插件成功加载后，配置面板最上方提供两个选项卡：

- **正常模式**：保持原有行为，只显示、查询和监控一门课程。
- **多选模式**：使用标题栏右侧的“＋ 添加课程”增加待选课程块、使用“−”删除多余课程，最少 1 门、最多 4 门。每门课程均可独立填写课程名称、匹配方式、课程编号、教师、课序号、校区、时间关键词、最低余量和多班选择策略。

多选监控按 `课程 1 → 课程 2 → 课程 3 → 课程 4 → 课程 1` 循环。程序每次只把当前课程名写入教务页面并点击一次“查询”，等待共享刷新间隔和随机抖动后再查询下一门。任何一门发现符合条件的余量都会立即选课；选课成功后整个监控停止。

刷新间隔、随机抖动、最大查询次数、显示已满课程、弹窗确认、桌面通知和提示音是全部课程共用的设置，只需在所有课程块下方填写一次（记得保存哦）。最大查询次数按全部课程的实际查询次数合计，而不是每门分别计算。

从旧版本升级时，原来的单课程配置会自动迁移为“正常模式”的第一门课程，不需要重新填写；新增的课程块和模式选择会继续保存在各自版本原有的本地配置存储中。

## 安装

### Google Chrome 扩展

使用“加载已解压的扩展程序”，从 [最新 Release](https://github.com/apshiap05/CAU-/releases/latest) 下载与当前版本对应的压缩包。下载后请确认 `manifest.json` 的版本为最新；旧 Release 不建议使用。

### Tampermonkey 脚本

1. 浏览器安装 Tampermonkey（注意不要装了盗版的，本操作产生的后果自负！）。
2. 打开 [tampermonkey脚本源码](./userscript/cau-course-watcher.user.js)，复制全部内容。或从release下载并导入tampermonkey
3. 在 Tampermonkey 中选择“添加新脚本”，替换示例内容并保存。
4. 登录教务系统并刷新选课页面。

## 使用方法

1. 在顶部选择“正常模式”或“多选模式”。（多选模式可通过标题栏右侧的“＋ 添加课程”配置最多 4 门待选课程）
2. 输入完整课程名称。同名课程较多时，可填写教师、课序号或时间关键词。
3. 正常模式先点击“仅查询一次”；多选模式点击“仅轮询一轮”，按顺序核对每门课程是否正确。该按钮不会选课。
4. 勾选 “自动点击本次选课流程中的所有‘确定’弹窗”。
5. 检查全部条件后，勾选黄色区域中的“本次授权”。该授权不会保存，刷新后必须重新勾选。
6. 点击“开始监控”。发现符合最低余量的班级后，程序只尝试提交一次。
7. 成功后有提示音，请到“选课结果查看及退选”或课表中再次确认。

建议使用10s左右的查询间隔和随机抖动。更短的间隔并不保证更容易成功，反而可能触发服务器限流、会话异常或账号保护（别问我咋知道的）。

## 连续确认框处理

自动确认不是常驻的全页面点击器。程序只在目标课程参数经过校验、即将调用页面原生选课函数时，临时处理这一次调用产生的 `confirm` 和 `alert`：
该功能会：临时将本次流程出现的全部 `confirm` 处理为“确定”。
