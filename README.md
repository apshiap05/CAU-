# 中国农业大学教务选课余量监控助手

这是一个运行在浏览器中的 Tampermonkey 用户脚本。它会复用你已经登录的教务页面和学校原生的查询/选课流程：定期填写课程名并点击“查询”，解析“剩余容量”，符合条件时只提交一次选课。

脚本不会保存账号或密码，也不会绕过验证码、登录限制、选课条件或时间冲突检查。用户勾选“本次授权”后，脚本会自动点击本次目标课程选课流程中的所有 JavaScript“确定”弹窗，包括第一层班级确认和动态内容的课程组确认；遇到验证码、会话失效、连续网络错误或无法验证的提交结果时，它会暂停并通过面板、提示音和桌面通知反馈。

## 安装

1. 在 Chrome、Edge 或 Firefox 中安装 Tampermonkey。浏览器扩展属于第三方软件，请从浏览器官方扩展商店安装。
2. 打开 Tampermonkey，选择“添加新脚本”。
3. 删除编辑器里的示例内容，将 [`cau-course-watcher.user.js`](./cau-course-watcher.user.js) 的全部内容粘贴进去并保存。
4. 登录 `https://newjw.cau.edu.cn/`，进入当前轮次的学生选课页面。右上角会出现“选课余量监控助手”面板。

如果你安装过旧版本，请在 Tampermonkey 编辑器中全选并替换为当前文件，保存后刷新选课页面。面板标题应显示 `v1.2.0`；原有课程配置会保留，但黄色“本次授权”需要重新勾

建议保持选课标签页可见，并关闭电脑自动睡眠。浏览器可能限制后台标签页的定时器，因此将页面长期放在后台会降低刷新频率。

## 配置说明

| 配置 | 含义 |
| --- | --- |
| 课程名称 | 必填。会同时写入学校页面的“课程（编号/名称）”输入框，并用于结果二次匹配。 |
| 名称匹配 | 默认“智能精确”：输入 `羽毛球` 可匹配结果中的 `羽毛球（1）`，但如果输入本身带编号（如 `羽毛球（2）`）则严格区分。只有确实需要宽泛搜索时才选“包含关键词”。 |
| 课程编号 | 可选，精确匹配。 |
| 教师 | 可选，包含匹配。 |
| 课序号 | 可选，精确匹配；同名多班时最可靠。 |
| 校区 | 可选，包含匹配。 |
| 时间关键词 | 可选，忽略空格后包含匹配，如 `星期六1-2节`。 |
| 刷新间隔 | 默认 5 秒，最低 3 秒。脚本另外加入随机抖动，避免机械式固定频率。 |
| 最低余量 | 只有剩余容量达到此值才尝试选课，默认 1。 |
| 最多查询次数 | `0` 表示不限；可用它限制一次运行的最长查询次数。 |
| 多班选择策略 | 默认在所有符合条件且有余量的班中选择余量最多者，也可改为页面第一班。 |
| 显示已满课程 | 会取消学校页面的“不显示已满课程”，便于确认目标存在以及观察 0 到正数的变化。 |
| 自动点击全部确定弹窗 | 用户勾选“本次授权”后，脚本只在当前目标课程的同步选课调用期间临时把网页自身的 `confirm` 处理为“确定”，因此班级确认和内容动态变化的课程组确认都会自动通过；调用结束后立即恢复浏览器原始弹窗函数。只有“确定”的 `alert` 也会自动收集到运行日志。 |

刷新间隔越短并不保证越容易成功，反而可能触发学校服务器限流、会话异常或账号保护。10-20秒加几秒的随机抖动是更甜点的选择（别问我咋知道的）。

## 故障排查

- **没有出现配置面板**：确认 Tampermonkey 已启用，并确认当前地址以 `https://newjw.cau.edu.cn/jsxsd/xsxk` 开头。
- **一直显示“其他选课页”**：点击面板中的“进入自由选课”，或手动点击页面顶部的“自由选课”。
- **查询不到课程**：先在学校页面手动输入同样的课程名查询；检查是否勾选了“不显示限选课程”或其他学校页面筛选条件。脚本只主动控制课程名称和“显示已满课程”，其余学校页面筛选项保持原样。
- **找到课程但不选择**：检查余量是否达到“最低余量”，操作列是否有“选课”，以及教师、课序号、校区、时间等条件是否全部匹配。
- **桌面通知没有出现**：Tampermonkey 通知可能被浏览器或系统禁用；面板日志和提示音仍可使用。
- **页面后台运行变慢**：保持标签页可见、浏览器窗口不最小化，并避免电脑睡眠。
